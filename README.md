# DoAPizza

Полнофункциональное приложение для заказа пиццы с дополнительным интерфейсом через телеграм бота.

## Архитектура

Проект состоит из четырёх сервисов:

| Сервис | Описание | Стек |
|---|---|---|
| `backend` | REST API + панель администратора | Django 5.1, DRF, PostgreSQL 17 |
| `frontend` | Веб-интерфейс для клиентов | React 19, Vite, React Router |
| `tgbot` | Telegram-бот для приёма заказов | Python, aiogram |
| `nlp-service` | NLP-микросервис для парсинга заказов | Python, FastAPI, OpenAI-совместимый LLM |


В каждой директории есть свой README файл с описанием сервиса и инструкцией по развертыванию.
